# Rockett Finance: feedback

[Rockett Finance](https://finance.rockettgenealogy.ie) is a private, local-first envelope budget
with Irish tax, pension and welfare planning. Your figures never leave your device, so nobody can
see your books: when something goes wrong, this is where you tell us.

- **Something broke?** [Report a problem](../../issues/new?template=problem.yml).
- **Want something?** [Ask for a feature](../../issues/new?template=request.yml).
- **A tax or pension figure looks wrong?** [Report a rules error](../../issues/new?template=rules.yml),
  with the Revenue or Citizens Information page that says otherwise.
- **Bank statement would not import?** Open a problem and say which bank and which export option
  you used. Never attach the statement itself; a few made-up rows in the same layout are enough.

Please do not post account numbers, balances or anything from your real books. The app's code is in
a separate repository that is not public yet; this one is only for talking.
